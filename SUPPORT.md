# Support

## How to file issues and get help

This project uses GitHub Issues for feedback about the Azure SQL Developer Hub itself: a page
that is wrong or out of date, a build prompt that does not work as written, a broken link, or a
problem with the site. Please search the
[existing issues](https://github.com/microsoft/azure-sql-dev-hub/issues) before filing, to avoid
duplicates.

Open a new issue at
[github.com/microsoft/azure-sql-dev-hub/issues/new](https://github.com/microsoft/azure-sql-dev-hub/issues/new).
Tell us which page or prompt you were using, what you expected, and what happened.

Issues here are about this site and its content. For the Azure SQL Database service itself, start
with the
[Azure SQL Database documentation](https://learn.microsoft.com/azure/azure-sql/database/), and
use your Azure support plan for anything affecting a running database.

For the agent skills this site links to, file issues in the
[Microsoft SQL agent skills repository](https://github.com/microsoft/microsoft-sql).

## Microsoft Support Policy

Support for the Azure SQL Developer Hub is limited to the resources listed above.
