A terminal in GitHub Copilot CLI types the prompt from `demo.prompt` (index.md) with the first app's name, shows the skills and the build once, and the first app opens below the terminal's last line, overlapping only its empty bottom edge so no line is covered. After that the terminal stays as it is: only the app name in the prompt and the app picture change, through `demo.apps` and around again. Only the first app and name show until the script moves on, so pages without scripts, and visitors who ask for reduced motion, see it alone and finished. The run is illustrative, not a recording. Screen readers get one label for the whole picture, the shown app's `alt`. The apps come from _includes/app-shot.html, shared with the Build section's app cards. They keep a light Azure look in both site themes, as the terminal stays dark in both. Styles and timing live in the home layout. Each element rests in its finished state, and --d is when it appears, in seconds after the page loads. --n is the number of characters typed, and --dur is how long typing them takes.
