This site uses Microsoft Clarity to understand how visitors use the site through
behavioral metrics, heatmaps, and session replay. We use this information to
improve site usability.

Clarity is configured with Strict masking and Clarity cookies disabled. This
site does not send custom user identifiers to Clarity.

For more information about how Microsoft processes data, see the
[Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).
